# Evaluation Module

This evaluation module is adapted from [FastSC](https://github.com/yongshanding/FastSC).

## Overview

This module provides tools for evaluating quantum circuit execution on superconducting devices, including:

- Success rate calculations
- Crosstalk and decoherence modeling
- Circuit benchmarking
- Performance metrics

## Attribution

The original codebase can be found at: https://github.com/yongshanding/FastSC

Modifications have been made to integrate with the QPlacer framework.
